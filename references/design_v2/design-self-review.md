> L1 摘要：`references/design_v2/design-self-review-summary.md`
> 本文档合并原 `design-taste-frontend.md` + `gpt-taste.md`，同时覆盖实现气质校正和视觉裁判两个角色。

## Part A: 实现气质校正（原 design-taste-frontend）

### 输入前提

开始实现前必须确认 DESIGN.md 已明确：页面类型、DESIGN_VARIANCE、MOTION_INTENSITY、VISUAL_DENSITY、Section Blueprint、图片与背景策略、移动端降级方案、负向红线。任一缺失先补设计。

### 全局实现底线

- 禁止系统默认字体栈主导
- 禁止纯白画布 + 默认蓝按钮
- 禁止所有模块共用同一容器/节奏/阴影
- 主容器内边距 ≥ 24px
- 禁止单层脏黑重阴影；用细边框 + 低透明度多层空气阴影
- 禁止白字压复杂图无遮罩
- 禁止用图片掩盖信息结构薄弱
- 禁止 TODO / ... / 占位注释 / 半截代码

### 页型实现要点

**Marketing / Landing**：首屏清晰抓手；卖点 section 节奏变化；CTA 主次要明确；图片/留白服务转化路径。禁止做成后台首页、全页同构、只靠渐变撑高级感。

**SaaS / Dashboard / Tool**：可扫读性优先；搜索/筛选/状态标签有秩序；空状态/加载态/错误态不能塌成一句文案；低装饰靠排版/层级/间距控质感。禁止大图抢首屏、默认蓝白、数据卡同权重。

**Story / PPT / Scrolltelling**：章节推进感；滚动效果需有叙事收益；图片/动态为文字让路；移动端降级为顺序堆叠+轻 reveal。禁止无章节硬上 ScrollTrigger、复杂背景压正文、只有形式变化无信息推进。

**Hybrid**：主页型控骨架，副页型增强局部；叙事和业务共享视觉语言但不共享节奏；转换处自然。禁止前后像两个站点拼接。

### 组件质感要求

- 按钮：主 CTA 抢眼，次 CTA 收敛，禁止同色同重
- 卡片：区分主要/次要/辅助，不是重复壳子
- 搜索筛选：内置图标 + 合并输入区，避免生硬色块按钮
- 标签状态：色相克制、层次清晰的语义色，禁止高饱和红绿铺底
- 数据块：数值/标题/说明/趋势有明显字阶差
- 空状态：图形 + 引导文案 + 下一步动作，禁止只有一句"暂无数据"

### 图片安全规则

素材先下载到 `src/assets` 再 import；背景图和主视觉图提前定义用途与遮罩；默认占位图仅开发期临时使用；SaaS/Tool 不得用大图挤压业务信息。

## Part B: 视觉裁判（原 gpt-taste）

### 诊断维度（8 维）

1. **页型匹配**：是否在服务该页型目标
2. **结构节奏**：section 主次、推进、停顿
3. **层级权重**：标题/正文/数据/控件级差
4. **可读性**：背景/图片/遮罩/对比度安全
5. **密度控制**：过稀/过挤/刚好
6. **组件气质**：是否廉价或通用
7. **移动端成立**：375px 保住信息结构
8. **模板味风险**：是否像一键生成

### 页型专项检查

**Marketing**：首屏强锚点、卖点节奏变化、CTA 明确、不像 SaaS 套壳。
**SaaS**：可快速扫读、主数据区明确、搜索筛选有秩序、不过度依赖装饰图。
**Story**：章节真推进、动效有叙事收益、图片不抢正文、移动端正确降级。
**Hybrid**：主页型清晰、副页型只增强局部、前后不断裂。

### 模板味识别特征

- 所有 section 同宽容器/同卡片壳子/同节奏
- Hero = 标题+副标题+两按钮+右侧图片
- 只换文案主色，不换层级节奏视觉重心
- 渐变/模糊/发光覆盖结构薄弱
- 按钮卡片几乎同权重

### 严重度分级

- **P0**：直接不可交付（正文不可读、关键操作不可见、页型完全错位）
- **P1**：主要视觉失败（层级崩塌、业务页不可扫读、营销页无抓手）
- **P2**：明显降质（模板味重、组件廉价、图片策略失控）
- **P3**：可优化项（细节层次偏弱、局部节奏略平）

### 问题到修正动作映射

- 主次不清 → 指出哪个区域升权/降权
- 信息过挤 → 删层/换布局/降 VISUAL_DENSITY
- 图片压字 → 加遮罩/换裁切/换图/取消叠字
- 工具页太像营销页 → 收回装饰图，提升数据层级和控件秩序
- 营销页太像工具页 → 重做 Hero 锚点和 section 节奏
- 模板味重 → 指出重复结构位置，要求节奏差异化

### FAIL 硬线

任一触发即 FAIL：页型目标不成立、关键文本不可读、工具页信息难扫读、营销页无抓手/节奏/CTA 主次、故事页无章节推进却依赖重动效、移动端结构崩塌、整体模板味。

### 输出格式

```md
## Taste Review
verdict: PASS | FAIL
pageType: Marketing | SaaS | Story | Hybrid

### Core Findings
- [P0/P1/P2/P3] 问题

### Type Fit
- 是否符合该页型目标

### Template Smell
- 模板味来自哪里

### Image Safety
- 图片或背景是否破坏可读性

### Required Fixes
- 必改项（具体动作，非抽象评语）
```
