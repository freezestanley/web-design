# 设计自审检查清单（L1 摘要）

> L2 全文：`references/design_v2/design-self-review.md`
> 用途：design.md 完成后、交给用户确认前的合并自检。一次读取完成 taste-frontend + gpt-taste 的双重校验。

## READ_FULL_IF

满足以下任一条件时，才读取 L2 全文：

- 下方速查表中有 ≥2 项判定为"不确定"或"不通过"
- 页型为 Hybrid 且主/副页型交界点模糊
- 页面包含自定义动效（GSAP / Framer Motion / rAF）且不确定是否过度
- 首次使用该页型模板，需要完整实现指引

否则，用本摘要即可完成自审。

## 8 维速查自检

逐项打分 PASS / WARN / FAIL：

| # | 维度 | 核心问题 | 判定 |
|---|------|---------|------|
| 1 | 页型匹配 | 页面是否真的在服务该页型目标？ | |
| 2 | 结构节奏 | section 是否有主次、推进和停顿？ | |
| 3 | 层级权重 | 标题/正文/数据/控件是否拉开级差？ | |
| 4 | 可读性 | 图片/背景/遮罩/对比度是否安全？ | |
| 5 | 密度控制 | 信息过稀、过挤还是刚好？ | |
| 6 | 组件气质 | 按钮/卡片/标签是否显得廉价或通用？ | |
| 7 | 移动端成立 | 375px 下是否保住信息结构？ | |
| 8 | 模板味 | 结构和样式是否像一键生成的模板？ | |

## 模板味快速识别

出现 ≥2 条即标记 WARN：

- 所有 section 同宽容器、同卡片壳子、同节奏
- Hero = 标题 + 副标题 + 两按钮 + 右侧图片的标准排法
- 只换文案和主色，不换层级、节奏和视觉重心
- 用渐变/模糊/发光覆盖结构薄弱
- 所有按钮和卡片几乎同权重

## FAIL 硬线（任一触发即 FAIL）

- 页型目标明显不成立
- 关键文本在图片/背景上不可读
- 工具页因装饰优先导致信息难扫读
- 营销页无首屏抓手、卖点节奏或 CTA 主次
- 故事页无章节推进却依赖重动效
- 移动端结构崩塌
- 整体呈现明显模板味

## 输出格式

```md
## Design Self-Review
verdict: PASS | FAIL
pageType: Marketing | SaaS | Story | Hybrid

### Findings

```
