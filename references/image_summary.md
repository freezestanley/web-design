## 6 问必答（L0 内联，无需读取）

1. 这页是否真的需要图片
2. 图片扮演什么角色（主视觉/说明/情绪/产品演示/纯背景）
3. 图片在哪个 section
4. 是否需要遮罩、裁切、焦点保护
5. 移动端如何降级
6. 缺图 fallback 是什么

## 页型图片策略速查

| 页型 | 适合 | 禁止 |
|------|------|------|
| Marketing | Hero 主视觉、场景图、品牌氛围图 | 每段塞装饰图、廉价素材撑高级感 |
| SaaS/Tool | 产品截图、空状态插画、少量说明图 | 大图抢首屏、图多于信息 |
| Story | 章节主图、情绪背景、视频/动态背景 | 只有情绪图无信息推进、复杂背景压正文 |
| Hybrid | 主页型定主策略，副页型局部借用 | 同页两套不同图片气质 |

## 遮罩规则速查

- 白字/浅字压图 → 必须有遮罩/暗化层/承托容器
- 遮罩服务可读性，不是制造氛围感
- 遮罩后仍不可读 → 换图优先于堆滤镜

## 移动端降级速查（375px）

- 更紧裁切 / 取消背景视频 / 压图标题改图下标题 / 多图改单图或纯色
- 读不清、点不准、图裁坏 → 图片策略失败

## 素材落地最小规则

- 下载到 `src/assets/<meaningful-name>.jpg`
- React 中 `import heroImage from "../../assets/hero-image.jpg"` 后 `<img src={heroImage} />`
- 禁止 `src="/assets/..."` / `src="./assets/..."` / 外链 URL 直塞 JSX
- 默认占位图仅开发期临时使用，审计阶段必须替换
