# Vitectrl Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a managed dev-preview controller in `scripts/vitectrl/` that keeps only the most recent five controller-owned Vite services.

**Architecture:** Introduce a small controller layer with a fixed registry file and reusable process helpers. The CLI entrypoint delegates to controller functions for `start`, `status`, and `cleanup`, while tests use a fake dev server to validate PID cleanup and max-five eviction without relying on real Vite startup.

**Tech Stack:** Node.js, CommonJS scripts, detached child processes, JSON registry file, Node.js test runner
